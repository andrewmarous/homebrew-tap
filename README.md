# Homebrew tap

Install Trailmix on macOS or Linux:

```sh
brew install andrewmarous/tap/trailmix
```

Update the CLI:

```sh
brew update
brew upgrade trailmix
```

The formula uses the checksums from the latest stable Trailmix release.
GitHub Actions checks for a new release daily. Maintainers can also run the Update formula workflow manually.

See [Trailmix](https://github.com/andrewmarous/trailmix) for setup and agent skill instructions.
